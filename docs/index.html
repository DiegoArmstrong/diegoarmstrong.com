About This Site

This website is generated using my very own static site generator! (written in Rust )

All content is written in Obsidian (markdown), and all the aesthetics are configured in a TOML file, then it is automatically converted into HTML and CSS. I did it this way to prioritize simplicity in website editing, so that I can very quickly create new blog posts and very easily change the aesthetics. I already love using Obsidian for technical documentation, journaling, notetaking, etc., so I figured it’d be nice to also write blog posts here.

Also, I have had an itch to learn Rust properly for a long time and I figured this would be a fun and simple enough project to gain some fluency in the language.
