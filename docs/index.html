About This Site

This website is generated using my very own static site generator called alloy! (written in Rust)

All content and aesthetics are written in Obsidian (markdown), then alloy converts everything into their respective website-serving equivalents (HTML/CSS). I did it this way to prioritize simplicity in website editing, so that I can very quickly create new blog posts and very easily change the aesthetics. I already love using Obsidian, so I figured it’d be nice to also build my website on here.

Also, I have had an itch to learn Rust properly for a long time and I figured this would be a fun and simple enough project to gain some fluency in the language.
